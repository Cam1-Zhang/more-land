# AI Werewolf — 产品简述

## 一句话

**AI Werewolf（AI 狼人杀）** 是一款移动端狼人杀练习应用：由 **1 名真人玩家 + 11 名具备固定人设与难度分层的 AI** 组成 12 人局，支持标准板与狼美人板，内置新手教学与角色图鉴；AI 发言可由大模型增强（配置 API Key），无密钥时自动使用本地规则化发言兜底。

## 定位

- **目标用户**：想随时练习狼人杀、凑不齐好友桌、或需要循序渐进学习规则的玩家。
- **核心价值**：无需组局即可跑完整昼夜流程；AI 在讨论环节结合对局日志发言，并优先回应真人玩家，避免「首置位编造」破坏沉浸感。
- **边界说明**：**组队开局**（邀请好友 / 输入房间号）当前为 **演示联机流程**（房间号、邀请、准备），非完整实时多人后端；单人练习与教学链路为当前主力场景。

## 核心能力（与实现对齐）

| 模块 | 说明 |
|------|------|
| **首页** | 单人对局、组队开局、新手教学、角色图鉴；右上角齿轮进入个人设置 |
| **个人设置** | 中/英界面语言；昵称（局内「我」）；6 款 Q 版头像 |
| **选角** | 按难度（Novice～Hard）筛选 AI 池；任选 11 名 AI；两种板型；支持随机选人；图鉴模式仅浏览 |
| **新手教学** | 分步引导（含选版）；选版阶段可进入设置 |
| **游戏房间** | 昼夜阶段推进、夜间技能顺序（含狼美人局）、讨论与投票等；教学局可含遗言规则提示 |
| **国际化** | 关键界面中文 / English |

## 体验与形态

- **平台**：React Native（Expo）。
- **方向**：应用锁定 **横屏**；首页等界面在宽屏下采用双栏布局，窄屏下纵向卡片。
