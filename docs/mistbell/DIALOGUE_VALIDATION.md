# 居民分支对话与住宅站位

验收日期：2026-10-19。

## 内容与交互

- 48 位居民各有一件符合人设的日常小事：第一轮 3 个回答、第二轮 2 个回答；隔一天后有后续结果与 2 个回应，共 336 个回答选项。
- 回应可增加 1–2 点好感，不合适的回应可能降低 1 点，普通回应不加分；实际好感限制在 0–100。
- 日常话题不泄露未解锁的主线。与 NPC 对话时，只会触发已满足章节、日期、地点、前置事件、材料条件的相关故事。
- 主线原先自动采用第一个回答的问题已修复，现在显示玩家可选回答，再显示对应回复。
- 已选回答立即写入原存档；关闭、刷新后继续第二轮，不重复发放好感。次日跟进不能当天提前触发，同一个已完成话题不重复奖励。
- 当前是每人一个两日生活小事件与已有主线、邻里和关系事件组合，不是运行时无限生成的新台词。完成的小事件保留结果，不自动重置。
- 页面直接显示一段完整发言及回应选项；线性剧情演出仍使用原有逐句展示。

## 站位

室内 NPC 检查可见身体范围，避开完整家具矩形与墙体。出生点、驻留点、巡逻路径、插值移动和同行伙伴均应用避让；不靠隐藏住户来解决重叠。室外人物与原场景继续使用原有边界。
