# 家庭住宅与家具交互验收

2026-10-14，本地开发版本。

## 实现范围

- 48 位居民分配到 23 户：16 户家庭、7 户独居；家庭关系与住所表见《家庭与住所.md》。
- 6 种像素室内布局供不同家庭共用；5 张室外家庭街景已接入场景与地图。
- 床、桌椅、沙发、厨房、书架、相册等主要家具设有交互点及碰撞。
- 其他居民的床仅可查看，不能睡觉或借宿；过夜仍只能回玩家农舍。
- 家庭聚会按日安排，角色不能重复出席多个聚会；人物到齐才显示剧情入口。

## 自动验证

- `test-mistbell.mjs`：14 章、41 个事件、16 条线索、161 次玩法操作通过。
- `test-mistbell-living-world.mjs`：90 个道路方向连接、2016 个资源位置、768 个居民姿态及日程通过。
- `test-mistbell-neighbors.mjs`：48 人、23 户、62 条关系、36 个攻略分支、16 段生活剧情通过；覆盖床权限、家具效果、旧住所存档迁移以及聚会人员冲突。
- `test-mistbell-scenes.mjs`：900 个交互目标可达性检查通过。
- 全项目 TypeScript 检查仍有既有的其他模块错误；输出中没有 Mistbell 模块错误。运行时需增大 Node 栈空间以完成该项目的类型检查。
