## 户型

- **榛木老宅**：三代老宅：北侧三间卧室，西侧长厨房，东侧宽客厅，中间过厅连接南门。
- **风车檐屋**：折角家庭住宅：两间卧室在北侧，第三间在西侧；厨房朝北，横向客厅连接南侧门厅。
- **北坡观星宅**：带观测书房的翼宅：西北为大书房，卧室分布在北侧与西翼，厨房在东翼，南侧是独立起居室。
- **棋盘石屋**：棋室位于北侧中央，两侧和东翼为三间卧室；中央长廊连接西南厨房和南侧书房。
- **白石问答屋**：紧凑的独居折角小宅：北端书房，中部一间单人卧室与小客厅，南端厨房和门厅；没有家人房间。
- **蓝窗宅**：北侧两间卧室与档案书房，东侧第三间卧室；客厅横向展开，厨房位于东南角。
- **赤尾坡屋**：围绕中央过厅的错层平面：西侧两间卧室、东北卧室，北客厅、西北厨房、东侧书房。
- **常青门宅**：西侧两间卧室上下分布，北端厨房，中部客厅向东延伸，南侧为门厅。
- **金狮宅**：横向宽厨房夹在两间卧室之间，南侧整片家庭客厅，下接紧凑门厅。
- **水杉小屋**：紧凑的四室折角小屋：西北卧室、东北工作书房，西南厨房连着南侧起居室。
- **暮藤屋**：北端独立卧室，中央客厅，南侧厨房与旧物书房并排。
- **铃影小屋**：无卧室和厨房的归所：北侧大书房，东侧旧物陈列室，西侧访客客厅，南侧门厅。
- **全景屋**：北侧宽观测书房，中部单人卧室与厨房，南侧横向起居室。
- **榆叶兄妹宅**：北侧两间卧室之间是工作书房；西侧厨房、东侧客厅，下接南门厅。
- **冬青宅**：西北宽主卧，西侧独立书房，中央起居室，南侧厨房和门厅。
- **榆灯宅**：横向楼上住宅：厨房、客厅与双人主卧由西向东排列，西南有种子记录书房。
- **红檐屋**：窄长住宅：北侧主卧与厨房，中部客厅，南侧书房和门厅。
- **紫藤门宅**：西北主卧和书房，西侧草药厨房，横向客厅通向东南收藏室。
- **黑栎兄妹宅**：横向船屋住宅：两端各有一间卧室，中间客厅，南侧分布厨房、门厅和航行书房。
- **三橡树屋**：三间卧室沿西侧分布，北侧厨房，中央横向客厅，东南书房。
- **霜石屋**：最紧凑的四室小宅：北侧单人卧室和书房，南侧小客厅与厨房。
- **铁门宅**：阶梯形独居住宅：东北单人卧室，中部书房与厨房，南侧横向起居室。
- **白栏宅**：西北单人卧室与书房相邻，西侧厨房，宽客厅朝东延伸，南侧访客门厅。
- **芦苇书匠屋**：分翼姐弟住宅：Rita卧室和书房在西侧，Ben卧室位于东翼；中间共用客厅，南侧厨房和门厅。
